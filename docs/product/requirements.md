# 需求清单

本文是需求编号的唯一来源：第一阶段（v0.1.0）已实现 F01–F14 与全部非功能需求，F15–F16 待规划，F17–F18 明确不在本期。新增或修改需求必须先有规格（见 [文档驱动开发流程](../process/doc-driven-development.md)），测试通过需求编号关联到这里，覆盖情况见 [追溯矩阵](traceability.md)。

## 背景与目标

项目把 ai-image-atlas（构建时解析 [image-inspirer](https://github.com/wukongnotnull/image-inspirer) 素材、生成 JSON 的纯静态站）重构为「React 前端 + Python 后端 + 数据库」的可运营图库：内容可以在线维护，检索更快，图片更轻。原站的问题与第一阶段的完整决策过程见 [需求与架构初稿](../archive/2026-09-28-需求与架构初稿.md)。

**非目标**：用户注册与收藏、搜索引擎收录（SEO）、在线调用模型生成图片、社区投稿与审核、多语言界面、原生移动端。

## 用户

| 角色 | 登录 | 核心场景 |
| --- | --- | --- |
| 游客 | 否 | 从分享链接进入案例页；按分类、标签或关键词找图，打开详情，复制提示词拿去生图 |
| 管理员 | 是（账号由命令行创建） | 维护案例、图片、分类与标签，重新导入上游快照并查看结果 |

## 非功能需求

| 编号 | 类别 | 要求 | 状态 |
| --- | --- | --- | --- |
| N01 | 首屏性能 | 列表每页 24 条，只返回提示词摘要；卡片用 480 px WebP 缩略图 | 已实现 |
| N02 | 接口性能 | 列表 P95 < 200 ms，搜索 P95 < 100 ms（千条级数据） | 已实现，未压测 |
| N03 | 搜索质量 | 中文按词匹配；英文容忍拼写错误；标题命中排在提示词命中之前 | 已实现 |
| N04 | 搜索一致性 | PostgreSQL 是唯一数据源；索引可随时重建；Meilisearch 不可用时降级 | 已实现 |
| N05 | 图片分发 | 文件名含内容 hash，长期缓存；起步由 Nginx 读本地磁盘 | 已实现 |
| N06 | 响应式与可访问性 | 320 px 宽起可用、无横向滚动；弹窗焦点陷阱与滚动锁定；键盘可操作 | 已实现 |
| N07 | 安全 | 后台需登录；Argon2 哈希；上传校验并重新编码（≤ 10 MB）；登录限流；HTTPS；Meilisearch 不对外 | 已实现，HTTPS 待上线配置 |
| N08 | 授权合规 | 保留上游 Apache-2.0 许可与来源；上线前完成 ICP 备案 | 许可已保留，备案待办 |
| N09 | 可运维 | 一条命令起环境；健康检查；数据库与图片每日备份到 OSS | 已实现，部署未实测 |
