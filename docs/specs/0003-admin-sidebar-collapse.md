# 规格 0003：后台侧栏可收起，主题切换与「查看前台」收进账号菜单

> 2026-09-29 批准并完成实施，规格冻结；系统现状见 [前端架构](../architecture/frontend.md)。按默认方案实施：主题切换与「查看前台」放进账号菜单；不加快捷键；退出登录只放在账号菜单里。

## 背景

后台侧栏（规格 0002 定下的 236 px 布局）有两个问题：

- **底部太挤、重心不对**：主题三选一胶囊、「查看前台」文字链接、当前用户三样东西竖着堆在底部。主题切换是个显眼的高亮组件，一次会话里却很少用；「查看前台」夹在中间，不属于任何一组。
- **侧栏宽度固定**：在 1280–1440 px 的笔记本上，案例表格被压窄，来源这类短列也会折行。管理员没法把侧栏让出来给内容区。

窄屏同样不一致：主题按钮在顶栏右侧，「退出」却在页面最底部。

## 目标与非目标

**目标**

1. 侧栏底部只留当前用户一行。主题切换、「查看前台」、退出登录收进点击用户后弹出的**账号菜单**，宽屏和窄屏用同一个菜单。
2. 宽屏（≥ 768 px）侧栏可以在展开（236 px）和收起（64 px，只显示图标）之间切换，选择保存在本机，刷新后保持。
3. 收起后导航照样好用：有可读名称和悬停提示，当前页仍然高亮。

**非目标**

- 窄屏的顶部横向导航本来就只占一行，不做收起。
- 前台图库吸顶栏里的主题切换位置不动。
- 不加键盘快捷键（见待定问题）。
- 不引入新依赖：账号菜单用现有的 Radix Popover，收起时的提示用 CSS 实现。

## 验收标准

**账号菜单**

- **AC-1** 宽屏下，侧栏底部只显示当前用户（头像、用户名），侧栏里不再直接出现主题切换和「查看前台」。
- **AC-2** 点击当前用户打开账号菜单，依次是：用户名、「查看前台」（新标签页打开 `/`）、「主题」三选一（浅色 / 跟随系统 / 深色，当前项高亮）、「退出登录」。选择主题立即生效，菜单保持打开；按 Esc 或点击外部关闭，焦点回到触发按钮。

**收起与展开**

- **AC-3** 侧栏品牌行右侧有「收起侧栏」按钮。点击后侧栏变为 64 px 的图标栏，只显示品牌标记、「展开侧栏」按钮、导航图标和用户头像；再点击恢复展开。
- **AC-4** 收起状态下，导航链接的可读名称不变（「案例」「分类」「标签」「导入与索引」）；鼠标悬停或键盘聚焦时，在图标右侧显示同名提示；当前页仍然高亮。账号菜单从头像右侧弹出。
- **AC-5** 收起或展开的状态保存在 localStorage 的 `atlas-admin-sidebar`，刷新和重新登录后保持；读取失败或值不合法时按展开处理。
- **AC-6** 收起或展开时，内容区宽度跟着变化，过渡约 200 ms（系统开启「减少动态效果」时直接切换），过程中不出现横向滚动条。

**窄屏**

- **AC-7** 窄屏（< 768 px）顶栏右侧是用户头像按钮，点开是同一个账号菜单。原顶栏的主题按钮和页面底部的「退出（用户名）」按钮去掉，也不显示收起按钮。

**不回归**

- **AC-8** 原有后台端到端流程全部通过，导航链接和按钮的名称保持原样。

## 方案

### 接口

无。

### 数据模型

无。前端新增一个 localStorage 键 `atlas-admin-sidebar`，值为 `collapsed` 或 `expanded`。

### 前端

**展开（236 px）**

```
┌────────────────────────┐
│ ✦ AI 图集 [后台]    ⇤ │ ← 收起侧栏
│                        │
│ ▣ 案例                 │
│ ▣ 分类                 │
│ ▣ 标签                 │
│ ▣ 导入与索引           │
│                        │
│ ────────────────────── │
│ (A) admin            ⌃ │ ← 点击打开账号菜单
└────────────────────────┘
```

**收起（64 px）**

```
┌──────┐
│  ✦   │
│  ⇥   │ ← 展开侧栏
│      │
│  ▣   │ ─┐
│  ▣   │  │ 悬停或聚焦时右侧显示「案例」等提示
│  ▣   │  │
│  ▣   │ ─┘
│      │
│ (A)  │ ← 点击打开账号菜单（从右侧弹出）
└──────┘
```

**账号菜单**

```
┌─────────────────────────────┐
│ (A) admin                   │
│     管理员                  │
│ ─────────────────────────── │
│ ↗ 查看前台                  │
│ ◐ 主题        [☀][🖥][☾]    │
│ ─────────────────────────── │
│ ⎋ 退出登录                  │
└─────────────────────────────┘
```

**代码结构**

| 位置 | 变化 |
| --- | --- |
| `features/admin/AdminLayout.tsx` | 侧栏布局改为 `grid-template-columns` 在 236 px 和 64 px 之间过渡；品牌行加收起按钮；收起时导航文字改为 `sr-only`，名称不变；去掉底部的主题切换、「查看前台」和窄屏底部的退出按钮 |
| `features/admin/AccountMenu.tsx`（新增） | 头像触发的 Popover：用户名、查看前台、主题（复用 `ThemeToggle`）、退出登录；宽屏与窄屏共用，收起时 `side="right"` |
| `features/admin/useSidebarCollapsed.ts`（新增） | 读写 `atlas-admin-sidebar`，localStorage 不可用时退回内存状态 |
| `features/admin/AdminLayout.tsx`（同上） | 收起状态导航提示：导航项内一个 `aria-hidden` 的文字块，悬停、`focus-visible` 时显示。实施时改用工具类写在组件里，`index.css` 不动 |

导航容器现在全尺寸都是 `overflow-x-auto`，宽屏下会裁掉向右伸出的提示，改为只在窄屏横向滚动。
